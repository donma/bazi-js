# 解讀驗證資料集

這個目錄與 `validation/external/` 分開。外部計算驗證可以檢查四柱、節氣、時區與規則輸出是否一致；解讀驗證則要檢查一個模型的命理解讀是否與獨立、可追溯的專業校核相符，兩者不能混為同一種「正確」。

## 目前狀態

目前只有資料契約與欄位規範，尚未收錄可被授權、可核實且具獨立校核的解讀案例，因此狀態是 `protocol-only`，不會在 SDK 或 Demo 宣稱解讀已被驗證。

每筆未來案例至少要保存：

- 固定輸入、Profile、引擎版本與比較範圍
- 獨立校核者或出版來源，不可由 BaziJS 自己產生 expected value
- `match`、`difference` 或 `undetermined`
- 差異原因與是否需要修改 canonical
- 不把生平敘述、醫療、財務或預測性斷語當成計算真值
