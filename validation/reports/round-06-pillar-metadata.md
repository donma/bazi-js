# Round 06：四柱干支五行／陰陽標籤線上抽樣

## 目的

驗證公開 API 的 `result.pillars.*.stemInfo` 與 `branchInfo` 是否正確保留天干、地支的五行與陰陽標籤。這裡的「陰金」是「陰陽屬性＋五行」的可讀合成標籤，不是納音。

## 外部來源

- [天干：陰陽五行表](https://zh.wikipedia.org/wiki/天干)：列出甲乙木、丙丁火、戊己土、庚辛金、壬癸水與陰陽分組。
- [地支](https://zh.wikipedia.org/wiki/地支)：提供十二地支的干支脈絡。
- [五行：干支對應表](https://zh.wikipedia.org/wiki/五行)：列出「甲乙寅卯木、丙丁巳午火、戊己四季土、庚辛申酉金、壬癸亥子水」及干支陰陽表。

## 抽樣範圍

以 1984–1995 年 12 月 12 日、`+08:00`、正月初一切年抽樣，覆蓋十二地支子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥；並檢查公開 API 的 `ganzhi`、`stemInfo.label`、`branchInfo.label`。

## 結果與限制

12／12 組與外部表格一致。這輪只驗證干支的固定五行／陰陽屬性，不驗證納音、十神、旺衰或任何命理解讀；來源頁面可能改版，因此 CI 使用本檔保存的擷取結果，不宣稱即時連線測試。
