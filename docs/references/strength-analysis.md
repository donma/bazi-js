# 日主強弱分析（strength-analysis.md）

- 規則名稱：得令/得地/得勢三維強弱模型＋同黨異黨量化
- ruleId：STR_STEM_TRANSPARENCY / STR_BRANCH_ROOT / STR_DE_LING / STR_DE_DI / STR_DE_SHI
- 採用方法：
  - 基礎分：天干透出（年月時干 8/12/10 分）＋地支藏干司權（月令 40、日 15、時 15、年 10，
    乘藏干權重；被沖之地支藏干 ×0.65）。
  - 得令：日主五行處月令旺/相（旺 1.2、相 1.0、休 0.6、囚 0.3、死 0.1）；旺相即得令。
  - 得地：本氣根 ≥1 或根氣 ≥2。
  - 得勢：天干有比劫/印星生助。
  - 綜合：同黨（比劫＋印）/ 總分 → 0–100；≥82 從強、≥55 偏強、45–55 中和、≥22 偏弱、<22 從弱。
  - 喜忌：扶抑法（強喜剋洩耗、弱喜生扶；從格順勢）。
- 公式：見 `src/strength/index.js`。
- 範例：1983-06-21 庚子日主 → 26.6 分偏弱，喜土金。
- 已知流派差異：權重模型本無定論（各派得令權重 30–60% 不等）；v1 權重可由 Rule Profile 覆寫
  （strength.deLingWeight 等）。此為「流派模型」非自然量測，文件與輸出皆須如此標示。
- canonical 選擇理由：兼顧得令/得地/得勢三要素的平衡模型，拒絕純數個數。
- 參考文獻：《子平真詮》論用神；《三命通會》論衰旺。
- 測試案例：結構＋evidence 鏈斷言（Lab evidence 頁籤）。
- 最後驗證日期：2026-09-08。

## 定位聲明
強弱分數為命理規則模型輸出，不可解讀為科學量測；喜用神僅供命理研究參考。
