# 胎元胎息命宮身宮（palace-calculation.md）

- 規則名稱：胎元（月干+1/月支+3）、胎息（日干支天地合）、命宮（14−月數−時數）、身宮（月數+時數−2）
- ruleId：AUX_TAIYUAN_001 / AUX_TAIXI_002 / AUX_MINGGONG_003 / AUX_SHENGONG_004
- 採用方法：
  - 胎元：月干序+1，月支序+3。
  - 胎息：日干取五合對應干、日支取六合對應支（STEM_HE / BRANCH_HE 表）。
  - 命宮：月數（寅月=1 … 丑月=12）＋時數（子=1 … 亥=12），命宮值 = (14 − 月 − 時) mod 12（1–12 映寅–丑）；
    天干以年干五虎遁配之。
  - 身宮：身宮值 = (月 ＋ 時 − 2) mod 12；天干同上。
  - 時柱未知時命宮身宮為 null（不強算）。
- 公式：見 `src/auxiliary/index.js`。
- 範例：戊申月 → 胎元己亥；庚子日 → 胎息乙丑。
- 已知流派差異：命宮另有「中氣過宮」起法、子時歸屬差一日之爭；胎息算法各派略有出入。
  爭議記 rule-differences.md，canonical 採掌訣數公式。
- canonical 選擇理由：子平掌訣主流，可程式化、無查表歧義。
- 參考文獻：《三命通會》卷五論胎元命宮。
- 測試案例：結構斷言（taiYuan/taiXi/mingGong/shenGong 干支與納音）。
