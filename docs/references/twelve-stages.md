# 十二長生（twelve-stages.md）

- 規則名稱：十二長生（長生沐浴冠帶臨官帝旺衰病死墓絕胎養）
- ruleId：STAGE_YANGSHUN_YINNI_001
- 採用方法：陽干順行、陰干逆行。長生位：甲亥、乙午、丙寅、丁酉、戊寅、己酉、庚巳、辛子、壬申、癸卯。
  目標支與起點之步數（順/逆 mod 12）即所處階段。輸出日主對四支＋各干自坐兩套。
- 公式：`src/core/constants/twelve-stages-data.js`（STEM_CHANGSHENG_MAP 查表）。
- 範例：甲日主坐亥為長生；丙日主坐午為帝旺。
- 已知流派差異：陰干起點另有一派與陽干同位；土長生另有一派寄水（申）而非寄火（寅）。
  canonical 採陽順陰逆、土寄火（戊寅/己酉）。差異記於 rule-differences.md。
- canonical 選擇理由：主流排盤軟體與《三命通會》十二長生表一致。
- 參考文獻：《三命通會》卷三。
- 測試案例：單元斷言（甲坐亥=長生、甲坐卯=帝旺）。
- 最後驗證日期：2026-09-08。
