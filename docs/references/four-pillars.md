# 四柱推算（four-pillars.md）

- 規則名稱：年柱（五虎遁起月gesetz）、月柱（節氣切月＋五虎遁）、日柱（JDN 定日）、時柱（五鼠遁）
- ruleId：YEAR_LICHUN_001 / MONTH_JIE_002 / DAY_JDN49_003 / HOUR_WUSHU_004
- 採用方法：
  - 年干支序 = (baziYear − 4) mod 60；baziYear 以立春分界（前歸上一年）。
  - 月建：交節後之地支為月建（立春寅 … 大雪子 … 小寒丑）；月干由年干五虎遁表
    WU_HU_DUN = [2,4,6,8,0,2,4,6,8,0]（甲己丙首 … 戊癸甲首）。
  - 日柱序 = (jdn + 49) mod 60，其中 jdn = floor(jdMidnight + 0.5)。
    錨點：1900-01-01 甲戌(10)、2000-01-01 戊午(54)、2024-01-01 甲子(0)，三獨立萬年曆來源驗證。
  - 時柱：時支由小時映射（23:00 起子時）；時干由日干五鼠遁表
    WU_SHU_DUN = [0,2,4,6,8,0,2,4,6,8]（甲己甲首 … 戊癸壬首）。
- 公式：見 `src/chart/*`。
- 範例：2000-01-01 12:00 → 己卯 丙子 戊午 戊午；2024-01-01 12:00 → 癸卯 甲子 甲子 庚午。
- 已知流派差異：年柱另有「正月初一切年」派；月柱另有「農曆初一切月」派；時柱另有夜子/早子分用法。
  皆已 Profile 化（yearBoundary / monthBoundary），canonical 採立春＋十二節。
- canonical 選擇理由：子平術主流（《三命通會》《子平真詮》皆以節氣定年月）。
- 參考文獻：《淵海子平》卷一；《三命通會》卷一；ximizi / rili.com / 8s8s / 月沙工具箱 / 易卦網。
- 測試案例：140 組 golden + BD-LICHUN/BD-ZISHI/BD-ANCHOR。
- 最後驗證日期：2026-09-08。
